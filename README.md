# Destrave sua Carreira

Landing page de curso com benefícios, módulos, depoimentos e oferta.

## Recursos

Composição em React e navegação das chamadas para a seção de inscrição.

## Tecnologias

React, JavaScript e Vite. Consulte package.json para as dependências e versões declaradas.

## Executar localmente

Use Node.js e npm compatíveis com as dependências declaradas:

```sh
git clone https://github.com/Felipegaldinos/cursos.git
cd cursos
npm install
npm run dev
```

Abra o endereço exibido no terminal. `npm run build` gera a versão de produção. `npm run preview` permite visualizar esse build.

## Onde começar no código

- `src/App.jsx` — ponto de entrada para entender o projeto.

## Estado atual

A página de oferta não comprova matrícula, pagamento ou emissão de certificado integrados. Revise esses fluxos antes de usar comercialmente.
